# 알고보니 초보자 마을이 Lv999

따뜻한 동화책 일러스트로 표현한 중세 마을 경영 시뮬레이션입니다. 게임 로직과 HTML/CSS/JS는 index.html 한 파일에 있으며, 건물·자연물·주민·재질 그림은 assets/illustrations/, 장식은 assets/decor/의 WebP를 Canvas에 그립니다.

## 실행

[GitHub Pages에서 플레이](https://gogeangs.github.io/medieval-village/)

로컬에서는 저장소 전체를 정적 웹 서버로 제공하세요. 별도 빌드나 패키지 설치는 필요하지 않습니다. 진행 상황은 브라우저(localStorage)에 자동 저장됩니다.

## 비주얼

- 청회색 시계탑 회관, 붉은 지붕 오두막, 벌목소·채석장·시장·빵집·선술집·밀밭을 같은 붓 터치와 3/4 시점의 일러스트로 표시합니다.
- 마을 그림 31개와 장식 4개, 방문객·선물 6개를 더한 총 41개 WebP: 기본 건물·자연물·주민 13개, 지형·종이 재질 5개, 가을 나무·어린 밀 2개, 겨울 변형 11개, 일반 장식 4개, 방문객 3명과 이야기 선물 3개. 투명 그림의 알파를 유지하며 부드럽게 축소·확대합니다.
- 봄·여름의 풀빛, 가을의 단풍, 겨울의 눈 덮인 건물과 나무를 표현합니다. 밀밭은 성장 모습과 겨울 휴경 모습을 보여 줍니다.
- 주민은 두 가지 일러스트를 바탕으로 방향과 걸음 표현을 바꾸며 움직입니다. 굴뚝 연기와 물결은 Canvas 효과를 유지합니다.
- UI는 종이 질감, 나무 테두리, 건물 그림 버튼으로 구성합니다. 휴대폰 자원 바 한 줄, 접는 퀘스트, 메뉴의 스킬 보기, 화면 빈 영역 중심 카메라와 가로 스크롤 건설 목록을 유지합니다.
- 초기 그림 요청은 최대 4개씩 처리하고 재시도합니다. 15초의 전체 로딩 기한 뒤에는 기존 Canvas 그림을 대체 표시해 게임을 시작합니다. 로딩 안내는 준비가 끝나면 사라집니다.
- 스프라이트는 게임 좌표의 8배 해상도로 캐시합니다. 지형은 계절마다 한 번 2304×2304(RGBA 약 20.25 MiB)로 캐시하며, 화면에 보이는 부분만 매 프레임 그립니다.
- 기존 지도 생성, 건물의 2×2칸 크기, 자원·일손·생산·퀘스트, 기존 저장 키와 데이터의 호환성을 유지하며 장식 정보를 추가합니다. 지붕과 나무 수관은 불투명 영역을 기준으로 탭할 수 있습니다.
- 강가 곡선과 마당은 시각 표현이며, 실제 건설 판정은 기존 타일을 따릅니다. 건설 미리보기는 2×2칸별 가능 여부를 표시합니다.

이미지는 Built-in ImageGen으로 제작했습니다. [생성 프롬프트](assets/illustrations/prompts.json)와 [에셋 정보](assets/illustrations/asset-info.json)를 함께 보관합니다. 경로는 모두 상대경로여서 Pages의 하위 경로에서도 작동합니다.

## 홈 화면 아이콘

선택한 시계탑 픽셀아트 앱 아이콘은 그대로 유지합니다. PNG 6종과 manifest 경로는 모두 상대경로여서 GitHub Pages의 하위 경로에서도 사용할 수 있습니다. 마스커블 아이콘은 건물 전체가 중앙 안전 영역 안에 들어가도록 여백을 둡니다. manifest는 설치 표시를 위한 설정이며, 오프라인 캐시를 추가하지는 않습니다.

## 플레이 방법

- 한 손가락으로 지도를 움직입니다. 두 손가락을 벌리면 확대하고 오므리면 축소합니다. 손가락 사이를 중심으로 배율이 부드럽게 바뀌며, 확대·축소 후 손가락을 떼어도 채집이나 건물 배치가 실행되지 않습니다. 컴퓨터에서는 마우스 휠로 확대·축소할 수 있습니다.
- 나무와 바위를 탭해 목재와 석재를 모읍니다. 한 번 탭할 때 3개, 다 베거나 깨면 3개를 더 얻습니다(나무 3번, 바위 4번). 나무와 바위는 10초마다 하나씩 다시 생기고, 그중 30%가 바위입니다.
- 시작 자원은 목재 50, 석재 30, 식량 40, 금화 30입니다.
- 하단 **건설** 탭에서 건물을 고르고 빈 땅을 탭한 뒤 **짓기**를 누릅니다. 건물은 2×2칸을 차지하며, 건설 완료 후 자동으로 채집 모드로 돌아갑니다.
- **건설** 탭의 **흙길**을 고르면 길 놓기 모드가 됩니다. 풀밭을 한 칸씩 탭하면 무료로 길이 생기고, 내가 낸 길을 다시 탭하면 지워집니다. 나무·바위·건물·장식·물 위에는 놓을 수 없고, **완료**를 누르면 길이 자연스럽게 이어진 모양으로 다시 그려집니다. 주민들은 새 길로도 다니며, 길 위에는 나무가 다시 자라지 않습니다. 저장 데이터에 `roads`(내가 낸 길 칸 목록)를 추가합니다.
- **건물 개수 한도**: 생산 건물(밀밭·벌목소·채석장·시장·빵집·선술집·목장)은 종류마다 마을회관 레벨 + 1개까지 지을 수 있습니다(Lv1 2개 … Lv5 6개). 오두막·창고·경비 초소·방앗간·대장간과 장식은 제한이 없습니다. 건설 칸에 '2/2 가득', 짓기 카드에 '0/2'처럼 개수가 보이고, 이미 한도를 넘게 지어 둔 저장은 철거하지 않고 새로 짓는 것만 막습니다.
- 건물을 탭한 뒤 **옮기기**를 누르고 빈 땅을 탭해 **이동**으로 확정합니다. 회관도 무료로 옮길 수 있고 레벨·일손·생산량은 유지됩니다. 취소하면 원래 자리에 남으며, 이동 완료 후 채집 모드로 돌아갑니다.
- 건물을 탭하면 업그레이드(최대 3레벨, 마을회관은 읍 등급부터 5레벨)와 철거를 할 수 있고, 시장 거래(경영 탭)에서 자원을 사고팔 수 있습니다.
- **짓기 비용이 점점 올라요**: 같은 종류를 이미 지은 개수만큼 비용이 늘어납니다(하나당 +40%, 오두막 +15%, 밀밭·노점 +25%, 창고 +30%, 5 단위로 올림). 업그레이드 비용은 기본 비용의 2배(1→2레벨), 4.5배(2→3레벨)입니다. 철거하면 기본 비용의 절반을 돌려받습니다.

## 화면 구성 (UI)
목업: `docs/mockups/` (GPT가 그린 6장). 실제 화면은 이 목업을 바탕으로 만들었습니다.
- **상단 자원 줄**: 목재·석재·식량·금화·주민마다 이름표와 **하루 단위 증감**(예: 하루 +36)을 보여 줍니다. 금화 증감에는 세금·통행세·유지비가 반영됩니다. 주민 칸에는 쉬는 주민 수가 나옵니다. 작은 화면(높이 700px 이하·폭 370px 이하)에서는 이름표를 숨깁니다.
- **만족도 칩**: 촌장 얼굴 + '만족 65 · 오늘 +128 금화'(오늘 영업 손익 = 건물 수입 + 세금 + 통행세 + 판매 − 유지비). 누르면 경영 탭이 열립니다. 오른쪽에 **지도 보기**(눈) 버튼과 **알림함**(종, 빨간 숫자 배지) 버튼이 있습니다.
- **아래 탭**: 마을 · 건설 · 주민 · **경영** · 이야기. 예전 상점 탭의 장식은 건설 › 꾸미기로, 물건 도감은 주민 탭으로, 시장 거래는 경영 탭으로 옮겼습니다.
- **경영 탭**: 위에 요약 카드 3장(오늘 손익 · 만족도 · 촌장 레벨), '건물 목록' 버튼, 기능 버튼 6개(마을 장부 · 정책·세율 · 보관함 · 시장 거래 · 마을 등급 · 왕국 지도), 아래에 만족도 요인. 하위 화면마다 '‹ 경영' 버튼으로 돌아옵니다.
- **건물 목록**: 모든 건물을 한 줄씩(그림 · 이름·레벨 · 하루 생산·유지비 · 공방 상태) 보여 주고, 오른쪽에 상태 표시(받을 물건 상자와 개수 / 일손 없음 ! / 업그레이드 가능 ▲)를 둡니다. 거르기: 전체 · 일손 없음 · 받을 것 있음 · 업그레이드 가능. '다 만든 물건 모두 받기'로 한 번에 받고, 정렬은 상태순 · 종류순 · 레벨순. 줄을 누르면 건물 화면이 열리고 '‹ 목록'으로 돌아옵니다.
- **건설 메뉴 분류**: 생산 · 주거·공공 · 상업 · 공방 · 길·성벽 · 꾸미기. 건설 탭을 열면 지금 목표에 필요한 건물의 분류가 먼저 열리고, 마지막 분류를 기억합니다. 건물 카드·건물 화면·자원 화면의 생산량도 하루 단위로 표시합니다.
- **알림함**: 유지비 밀림, 촌장 레벨업, 주민이 떠남, 위기 결과, 새 이웃, 마을 등급 승격을 날짜별(오늘·어제·N일)로 쌓아 둡니다(최대 40개, 저장 키 `inbox`, `inboxNew`). 짧은 안내 문구는 아래 탭·건설 서랍·확인 패널 바로 위에 뜨고, '새 이웃' 카드는 지도만 보고 있을 때 아래쪽에 나옵니다.
- **지도 보기 모드**: 보통 · 성벽 보호(성벽 안 땅을 연두색, 성벽 밖 건물과 문지기 없는 성문을 빨간 테두리) · 일손(일손 없는 건물) · 받을 것(물건이 다 된 공방, 띠에서 바로 모두 받기). 아래 설명 띠에 숫자를 보여 줍니다.

## 편하게 이어 하기 (UX)
- **자리를 비운 동안**: 게임을 닫거나 다른 앱으로 갔다가 돌아오면, 비운 시간(1분 이상, 최대 8시간)의 **절반만큼** 생산·세금·통행세·유지비를 계산해 줍니다. 창고 한도를 넘지 않고, 식량은 0 아래로 내려가지 않으며, 위기·계절·날짜·주민 이탈은 멈춰 있습니다. 공방은 비운 시간만큼(건물당 최대 60개) 슬롯에 물건을 쌓고, 짐꾼이 있으면 바로 보관함에 넣습니다. 결과는 '자리를 비운 동안' 카드로 보여 줍니다(저장 키 `seen`).
- **저장 백업**: 도움말·설정 › 저장 백업에서 '백업 만들기'로 코드를 만들어 복사하거나 .txt 파일로 저장합니다(앨범 포함). '백업 불러오기'에 코드를 붙여 넣거나 파일을 고르고, 한 번 더 눌러 확인하면 덮어쓰고 다시 시작합니다.
- **처음엔 단순하게**: 아직 쓸 수 없는 경영 기능(정책·세율은 촌장 Lv2, 보관함은 공방이 생기면, 시장 거래는 시장을 지으면, 왕국 지도는 등급이 오르면)은 자물쇠와 열리는 조건만 보여 줍니다. 건설 메뉴에서는 건물이 하나도 열리지 않은 분류를 숨깁니다. 주민이 10명이 될 때까지는 식량 부족을 뺀 불만 요인이 만족도를 깎지 않고(최저 45), 불만으로 주민이 떠나거나 증가가 멈추지 않습니다.
- **처음 여는 화면 안내**: 경영 · 정책·세율 · 장부 · 건물 목록 · 보관함 · 시장 거래를 처음 열면 짧은 설명 카드가 뜹니다('알겠어요'로 닫으면 다시 안 나옴, 저장 키 `intro`).
- **목표 항상 보기**: 위쪽 목표 칸에 지금 목표 이름과 진행도가 늘 보입니다.
- **모자랄 때 바로 가기**: 짓기·업그레이드에 재료가 모자라면 '벌목소로 가기'(없으면 '벌목소 짓기') · '채석장으로 가기' · '대장간으로 가기' · '시장에서 사기' 버튼이 함께 나옵니다. 알림함의 유지비·레벨업·이탈·새 이웃·등급 알림은 눌러서 해당 화면으로 갑니다.
- **새로 열림 표시**: 새로 지을 수 있게 된 건물은 건설 탭·분류·카드에, 새 정책·세율은 경영 탭·정책 칸에 빨간 점이 붙습니다. 그 분류를 보고 서랍을 닫거나 건물을 고르면 사라집니다(저장 키 `seenB`, `seenP`).
- **이어서 짓기**: 짓기 패널의 '이어서 짓기'를 켜면 한 채를 지은 뒤에도 같은 건물을 계속 놓을 수 있습니다(설정은 기기에 기억).
- **한꺼번에 업그레이드**: 건물 목록에서 지금 자원으로 올릴 수 있는 건물(싼 것부터, 마을회관 제외)을 모아 총비용을 보여 주고, 확인하면 한 단계씩 올립니다.

## 게임 시스템

| 건물 | 비용 | 일손 | 효과 | 조건 |
|---|---|---|---|---|
| 마을회관 | – | – | 주민 +5/레벨 | 시작 건물 |
| 오두막 | 목재 20 | – | 주민 +3/레벨 | |
| 밀밭 | 목재 15 | 2 | 식량 +1.5/초 (겨울 정지) | |
| 벌목소 | 목재 25, 석재 10 | 2 | 목재 +1.2/초 | |
| 채석장 | 목재 30 | 2 | 석재 +1.0/초 | |
| 시장 | 목재 40, 석재 20 | 2 | 금화 +0.6/초, 자원 판매 | |
| 빵집 | 목재 35, 석재 30, 금화 20 | 2 | 식량 +1.6/초 | 회관 Lv2 |
| 선술집 | 목재 60, 석재 40, 금화 50 | 3 | 금화 +1.2/초, 주민 증가 가속 | 회관 Lv2 |

- **주민과 식량**: 주민 1명당 식량 0.12/초를 소비합니다. 식량이 바닥나면 주민이 떠납니다.

## 영지 확장

- 지도는 7구역입니다. 처음에는 가운데 **초보자 마을**만 열려 있고, 나머지 6구역(강가·깊은 숲·언덕 위·바위 언덕·꽃밭·옛 폐허)은 안개에 덮여 있습니다.
- 이야기 목표 2개를 마치면 열린 땅과 맞닿은 구역에 깃발이 섭니다. 안개나 깃발을 탭하면 구역 카드가 열리고, 자원을 내 개척합니다. 개척한 구역의 깃발은 사라집니다. 개척 비용은 개척할수록 오르며, 3·4번째는 회관 Lv2, 5·6번째는 회관 Lv3이 필요합니다.
- 구역 보상: 강가 식량 +10%(식량 +40), 깊은 숲 목재 +10%(나무 추가), 언덕 위 금화 +10%(금화 +40), 바위 언덕 석재 +10%(바위 추가), 꽃밭 주민 상한 +4(꽃 장식 2개, 나무가 줄어 넓은 평지), 옛 폐허 모든 생산 +5%(금화 +120, 석재 +60). 옛 폐허는 강가나 꽃밭을 먼저 열어야 들어갈 수 있습니다.
- 안개 속 땅에는 건물·장식·길을 놓을 수 없고, 나무와 바위도 캘 수 없습니다. 저장 필드는 `zones`(연 구역 id 목록)입니다. 예전 저장은 건물·길·장식이 있는 구역을 자동으로 연 상태로 불러옵니다.
- 그림: `assets/frontier/`의 안개 무늬(`fog`), 깃발(`flagLocked`·`flagClaimed`), 잠긴 땅 가장자리 덤불(`thicket`), 개척 반짝임(`burst`)을 씁니다. 구역을 열면 그 구역 소품이 지도에 놓입니다: 강가 갈대와 선착장(`reeds`, 강둑), 깊은 숲 고목(`bigtree`), 바위 언덕 바위 무더기(`boulders`), 꽃밭 들꽃(`flowerfield`), 옛 폐허 돌담(`ruins`). 소품 자리에는 건물을 지을 수 없고, 저장 필드는 `props`입니다. 그림이 없으면 직접 그린 안개와 깃발로 표시합니다.

## 명소 복원

- 지도에 무너진 명소 5곳이 있습니다. 탭하면 명소 카드가 열리고, 자원을 내 3단계로 복원합니다. 단계마다 비계가 세워지고, 3단계를 마치면 모습이 바뀌며 효과가 영구 적용됩니다. 이야기 목표 2개를 마친 뒤부터 복원할 수 있고, 안개 속 구역의 명소는 그 구역을 개척해야 손볼 수 있습니다.
- 오래된 우물(초보자 마을): 주민 식량 소비 -15%
- 낡은 풍차(꽃밭): 식량 생산 +10%
- 무너진 망루(언덕 위): 위기를 놓쳐도 피해 절반
- 버려진 예배당(옛 폐허): 소문이 25% 덜 퍼짐
- 끊어진 돌다리(강가, 강 위): 방문객 간격 하루 → 3/4일
- 명소 자리에는 건물·장식·길을 놓을 수 없습니다. 저장 필드는 `lm`(명소별 위치와 단계)이며, 예전 저장은 빈 자리를 찾아 명소를 새로 배치합니다.
- 그림: `assets/landmarks/`의 무너진 모습(`*-ruin`)과 복원된 모습 5쌍을 씁니다. 복원 1·2단계에는 무너진 모습 위에 복원된 모습이 비치고 비계가 세워집니다. 그림이 없으면 코드로 그린 임시 그림을 씁니다.

## 물품 보관함 · 도구 · 시세

- **물품 보관함**: 자원 칸 › '물품 보관함 · 팔기', 창고 카드, 시장 판매 탭에서 열려요. 재료·음식 / 장비 / 도구 / 물약 / 던전 특산물로 나눠 보유 수, 쓰임, 입는 중·쓰는 중 수, 지금 값을 보여 주고, 시장이 있으면 1개·5개씩 팔 수 있어요.

## 마을 경영 (장부 · 촌장 레벨 · 만족도 · 정책)
마을을 키우는 경영 게임의 중심 시스템입니다. 상단의 날짜 줄(만족 수치)을 탭하거나, 촌장 정보·마을 자원 화면의 '마을 경영' 버튼으로 엽니다. 저장 키: `mg`.
- **마을 장부**: 하루(30초)마다 건물 수입, 세금, 물건 판매, 기타(보상·시장 거래), 건물 유지비, 짓기·구매를 '오늘 / 어제'로 보여 줍니다.
- **건물 유지비**: 초당 금화 × 레벨. 시장 0.1, 창고·노점 0.06, 빵집 0.15, 방앗간·목장·물약 상점 0.12, 대장간·경비 초소 0.2, 선술집·여관·연금술 공방 0.24, 길드·대성당 0.8. 오두막과 기본 생산 건물(밀밭·벌목소·채석장)은 없습니다. 금화가 모자라면 유지비가 밀려 만족도 -15.
- **세금**: 주민 1명당 초당 0.02 × 세율 × 만족도 배율(0.5 + 만족도/100). 세율은 촌장 Lv2부터 낮게(×0.6, 만족 +8) / 보통 / 높게(×1.5, 만족 −12).
- **주민 만족도 (0~100)**: 기준 55에 요인을 더한 목표치로 천천히 움직입니다. 식량 넉넉 +5 / 부족 −25, 빵(주민 10명부터, 보관함에 빵이 있으면) +8 / 없음 −6 — 주민은 사흘에 한 번 주민 30명당 빵 1개를 먹음(빵 배급 정책이면 2배), 빈 집 3채분 이상 +3, 쉬는 주민이 많음 −6, 즐길 거리(선술집·여관·노점·장식·명소·대성당, 주민 8명부터) −10~+12, 세율, 정책.
  - 70 이상: 주민이 더 빨리 모임. 30 미만: 주민이 더 오지 않음. 15 미만: 45초마다 주민 1명이 떠남.
- **촌장 레벨 (Lv1~30)**: 하루 결산마다 경영 점수(4 + 주민×0.3 + 하루 순수입/20(최대 40) + 만족도 보너스)가 쌓입니다. 필요 점수는 8×(Lv−1)². 호칭: 신참(1) → 어엿한(5) → 믿음직한(10) → 노련한(15) → 이름난(20) → 왕국이 아는(25) → 전설의 촌장(30).
- **정책**: 촌장 Lv3에 1칸, Lv8에 2칸, Lv15에 3칸. 시작할 때 금화 20 + 주민×2, 멈추는 건 무료.
  - 장날 지정(Lv3): 시장·선술집·여관·노점·물약 상점 금화 +20% / 식량 10% 더 먹음
  - 빵 배급(Lv4): 만족 +10 / 빵 수요 2배
  - 이주 장려(Lv6): 주민이 더 빨리 모임 / 세금 −30%
  - 근로 장려(Lv8): 모든 생산 +10% / 만족 −10
  - 검소한 살림(Lv10): 유지비 −30% / 만족 −5
  - 잔치 기금(Lv12): 만족 +8 / 하루 금화 10 + 주민 수
  - 무역 협정(Lv15): 물건 판매가 +15% / 유지비 +20%

## 성벽 공사 (울타리 · 돌 성벽 · 성문 · 망루 · 문지기)
건설 탭의 '성벽' 칸에서 길처럼 한 칸씩 탭해서 짓습니다. 같은 종류를 다시 탭하면 헐고 비용의 절반을 돌려받습니다. 울타리 칸을 돌 성벽으로 탭하면 바꿔 지어요. 저장 키: `walls` (칸 번호 → `{t, keep}`).

- **둘러싸기 계산**: 지도 가장자리에서 퍼져 나가 닿지 않는 칸이 '성벽 안'입니다. 성벽·망루·물·명소·문지기가 지키는 성문이 막고, 문지기 없는 성문은 열려 있어 막지 못합니다.
- **효과**: 성벽 안 건물 비율만큼 위기 피해 최대 −50%. 망루지기가 있는 망루마다 위기 대응 시간 +4초(3곳까지). 주민 8명 이상일 때 성벽 안 건물 80% 이상이면 만족 +6, 50% 이상이면 +3.
- **문지기**: 성문을 탭해 '문지기 세우기'(쉬는 주민 1명). 성문마다 통행세 금화 0.08 × (1 + 등급×0.25)/초(성문 4곳까지, 장부의 '통행세'). 망루지기는 쉬는 주민이 있으면 저절로 올라갑니다. 문지기·망루지기는 건물 일손을 다 채운 다음에 배정됩니다.
- **유지비**: 울타리 0.004, 돌 성벽 0.008, 성문 0.03(+문지기 품삯 0.05), 망루 0.1 /초.
- 그림: 가로 성문과 망루는 `assets/extras`의 gate-wood·gate-stone·tower-wood·tower-stone을 씁니다(옆에 돌 성벽이 붙으면 돌 그림). 문지기 없는 성문은 문이 열린 모습으로 보입니다. 울타리·돌 성벽 칸은 이어 붙이는 조각 그림(wall-wood/stone-h·v·post)으로 그립니다. 가로 칸은 좌우로, 세로 칸은 위아래로 반복하고, 모서리·끝·갈림길에는 기둥이 섭니다. 세로 방향 성문은 양옆으로 통로가 뚫린 문루 그림(gate-wood-v·gate-stone-v)을 씁니다.

## 이야기와 단서

- 하단 탭은 **마을 · 건설 · 주민 · 이야기 · 상점**입니다. 왼쪽 위 **촌장 Lv1** 버튼에서 스킬과 마을 현황을, ⚙에서 도움말과 새로 시작을 엽니다.
- 퀘스트 15개는 이야기 15화입니다. 보상을 받으면 그 화의 장면 카드가 열리고, **이야기** 탭에서 본 화를 다시 볼 수 있습니다.
- **주민이 한 명씩 찾아오는 구조**입니다. 처음에는 거의 텅 빈 마을에 마르타 할머니만 있고, 막마다 주민 한 명이 이사 와서 촌장을 몰래 돕다가 막의 끝에서 정체가 드러납니다.

| 막 | 화 | 찾아오는 주민 (집) | 정체 공개 |
| --- | --- | --- | --- |
| 1막 남아 있던 사람 | 1~3 | 마르타 (처음부터) | 3화 잔치와 비룡 |
| 2막 숲에서 온 사람 | 4~6 | 군터 (벌목소) | 6화 숲의 늑대 |
| 3막 비를 맞고 온 사람 | 7~9 | 브루노 (채석장) | 9화 닫히지 않는 문 |
| 4막 수상한 상인 | 10~12 | 피노 (시장) · 엘리스 등장 11화 | 12화 측정기가 울린 날 |
| 5막 무서운 손님 | 13~15 | 바르그 (선술집) | 14화 빗자루를 든 촌장 |

- 목표 순서: 목재 10 → 오두막 2 → 밀밭 → 벌목소 → 석재 10 → 주민 8 → 채석장 → 회관 Lv2 → 빵집 → 시장 → 판매 30 → 주민 25 → 선술집 → 첫 겨울 → 회관 Lv3.
- 집을 지어 주민이 이사 오면 '새 이웃' 카드가 뜨고, 그때부터 그 주민에게 **부탁**을 할 수 있습니다. 정체가 공개되면 도감에 숨은 기록이 열립니다.
- 장면 그림: 0·14·15화는 기존 그림, 8화는 기존 7화(바위), 11화는 기존 13화(다리) 그림을 씁니다. 나머지 11장은 `assets/story/v2/epNN.webp`(작은 그림은 `v2/thumbs/`)로 새로 그립니다. 그림이 없으면 빈 카드로 표시됩니다.
- 예전 저장은 받은 보상(`claimed`) 기준으로 본 화 목록을 새 순서에 맞게 다시 계산합니다(`storyV: 2`).
- **촌장 이름**: 프롤로그를 마치면 이름을 물어봅니다(최대 8글자, '나중에'로 건너뛰기 가능). 촌장 정보 화면의 '이름 바꾸기'로 언제든 바꿀 수 있고, 이야기 장면에서 촌장 대사 이름표로 쓰입니다(저장 필드 `name`, `nameAsked`).
- 새 게임을 시작하면(또는 처음 업데이트를 받으면) **프롤로그 '발령 추첨'**이 열립니다. 연수 꼴찌 신입 관리인 내가 역대 촌장이 석 달을 못 버틴 초보자 마을로 발령받는 이야기입니다. 이야기 탭과 촌장 정보에서 다시 볼 수 있습니다.
- **촌장의 비밀** 단서 3개(회관 2개, 마르타 집 1개)는 내가 이 마을로 온 진짜 이유의 실마리이며 촌장 정보 화면에 모입니다. 15화에서 발령장 뒷면의 추천인 서명이 밝혀집니다.
- 주민 집을 특정한 때(저녁, 계절, 이야기 진행)에 탭하면 **수상한 순간**(단서)을 발견합니다. 마르타 5개, 나머지 주민 3개씩입니다. 하루의 마지막 8초는 저녁으로 화면이 노을빛으로 물듭니다.
- 저장 데이터에 본 화 목록(`story`)과 찾은 단서(`clues`)를 추가합니다. 이전 저장은 빈 목록으로 시작하며 경제 규칙은 바뀌지 않습니다.

## 금화와 마을 꾸미기

- 시장 건물을 탭하면 **자원 구매 / 자원 판매**를 선택할 수 있습니다. 구매는 10개 단위이며, 교역 1레벨 기준 목재 10G·석재 15G·식량 8G입니다. 구매가는 같은 시점의 판매가보다 높고 교역 레벨에 따라 변합니다. 구매 자체는 채집·판매 퀘스트나 경험치를 올리지 않습니다.
- 하단 **상점**은 처음부터 열립니다. 들꽃 화단 12G(1×1), 나무 벤치 25G(1×1), 마을 가로등 45G(1×1), 돌 분수 120G(2×2)를 고른 뒤 빈 땅이나 길을 탭해 구매·배치를 확정합니다. 취소하면 금화를 쓰지 않습니다.
- 놓은 장식을 탭하면 무료로 **옮기기 / 보관하기**가 가능합니다. 보관품은 건설 › 꾸미기에서 무료로 다시 놓습니다. 보관품을 먼저 사용하며, 배치·이동 후 채집으로 돌아갑니다.
- 장식은 생산량·일손·주민 수에 영향을 주지 않습니다. 건물·자연물·다른 장식·강·다리 위에는 겹쳐 놓을 수 없고, 장식 자리에는 나무가 다시 생기지 않습니다.
- 기존 저장 키를 유지하고 장식 목록(decor), 보관함(decorBag), 장식 번호(decorNext)를 추가합니다. 이전 저장은 빈 장식 목록으로 자동 호환됩니다. 기존 자원·건물·진행 상황을 유지합니다.
- 새 그림은 내장 image_gen으로 만든 투명 일러스트 4종입니다. 최종 프롬프트와 이미지 정보는 `assets/decor/prompts.json`, `assets/decor/asset-info.json`에 기록합니다. 원본은 별도 보관하고 게임은 WebP를 상대경로로 불러옵니다. 로딩 실패 시 기본 그림을 표시합니다.

## 방문객과 이어지는 이야기

- **주민** 탭의 찾아온 손님 또는 마을 길 위의 손님/말풍선을 탭하면 이야기를 읽습니다. 목수 로안 → 요리사 미라 → 탐험가 루카 순서로 각각 두 번 찾아오는 의뢰 6개입니다. 첫 방문은 바로 열리며, 보상을 받은 뒤 다음 방문까지 게임 시간 30초를 기다립니다. 기한은 없습니다.
- **물자 주기**는 표시된 자원을 전달하고 바로 완료합니다. **주민 보내기**는 쉬는 주민 1명이 30~75초 동안 돕고 더 많은 금화와 친밀도를 받습니다. 파견 주민은 일손에서 제외되며, 도움 완료/취소 시 자동 복귀합니다. 준비는 게임이 진행되는 동안만 흘러갑니다.
- 완료 후 **보상 받기**를 눌러 금화와 친밀도를 받습니다. 물자 방식은 친밀도 +1, 주민 방식은 +2이며 중복 수령할 수 없습니다. 완료한 대화와 선택은 이야기 기록에 남습니다.
- 각 인물의 두 번째 의뢰는 로안의 꽃수레(2×2), 미라의 피크닉 식탁(2×2), 루카의 해시계(1×1)를 1개씩 줍니다. 이 선물은 구매할 수 없고 보관함에서 무료 배치·이동·보관할 수 있습니다.
- 기존 저장에 `visitors`(완료 기록, 다음 방문 시각, 파견 잔여 시간, 수령 대기)를 추가합니다. 이전 저장은 첫 방문부터 시작하며 기존 자원·건물·장식·보관품을 유지합니다. 파견/보상 대기 중 재접속해도 진행 상태를 유지하고 오프라인 시간을 추가하지 않습니다.
- 이미지 6종은 내장 image_gen으로 제작했습니다. `assets/visitors/prompts.json`과 `asset-info.json`에 프롬프트와 이미지 정보를 기록합니다. PNG 원본은 별도 보관하며 게임은 투명 WebP를 사용합니다. 그림 로딩 실패 시 Canvas 기본 그림으로 진행합니다.
