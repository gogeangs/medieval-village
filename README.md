# 작은 영지

따뜻한 동화책풍 일러스트로 표현한 중세 마을 경영 시뮬레이션 웹 프로토타입입니다. 게임 화면은 외부 이미지 없이 Canvas 코드로 그리며, 게임 로직과 스타일은 `index.html` 한 파일에 들어 있습니다. 홈 화면 설치용 PNG 아이콘은 `icons/`, 설치 정보는 `manifest.webmanifest`에 둡니다.

## 실행

`index.html`을 브라우저로 열면 바로 플레이할 수 있습니다. 진행 상황은 브라우저(localStorage)에 자동 저장됩니다.

## 비주얼

도트 외곽선 대신 곡선, 은은한 명암, 부드러운 그림자를 사용합니다. 청회색 시계탑 회관과 붉은 지붕의 목조 오두막, 둥근 나무, 굽이치는 강가를 차분한 초록색과 크림색으로 그립니다. UI는 둥근 종이 카드와 읽기 쉬운 숫자로 맞췄습니다.

- 건물 8종, 자연물, 주민, 자원 아이콘과 효과를 Canvas 경로로 생성합니다. 별도 이미지 에셋이나 빌드 과정은 게임 렌더링에 필요하지 않습니다.
- 스프라이트는 게임 좌표의 6배 해상도로 캐시하고 부드럽게 축소·확대합니다. 지형 캐시는 별도의 2배 해상도(1536×1536, RGBA 약 9 MiB)를 사용해 모바일 메모리 사용을 제한합니다.
- 계절이 바뀌면 색상·눈·작물 표현과 지형 캐시를 새로 만듭니다. 강물, 굴뚝 연기와 주민만 프레임마다 움직입니다.
- 기존 지도, 건물의 2×2칸 크기, 자원·일손·생산 규칙, 퀘스트와 저장 형식·키를 유지합니다. 지붕과 나무 수관은 불투명 영역을 기준으로 탭할 수 있습니다.
- 지도 바깥 장식 숲, 종류별 마당, 건물 레벨 표시와 일손 부족 표시를 유지합니다. 강가의 곡선은 시각 표현이며 실제 지도와 건설 판정은 기존 타일을 따릅니다.
- 휴대폰의 자원 바 한 줄, 접을 수 있는 퀘스트, 메뉴의 스킬 보기, 화면 빈 영역 중심 카메라와 가로 스크롤 건설 목록을 유지합니다.
- 건설 미리보기는 2×2칸별 가능 여부와 마당을 표시합니다.

## 홈 화면 아이콘

선택한 시계탑 픽셀아트 앱 아이콘은 그대로 유지합니다. PNG 6종과 manifest 경로는 모두 상대경로여서 GitHub Pages의 하위 경로에서도 사용할 수 있습니다. 마스커블 아이콘은 건물 전체가 중앙 안전 영역 안에 들어가도록 여백을 둡니다. manifest는 설치 표시를 위한 설정이며, 오프라인 캐시를 추가하지는 않습니다.

## 플레이 방법

- 화면을 드래그해 지도를 움직이고, +/− 버튼(또는 마우스 휠)으로 확대·축소합니다.
- 나무와 바위를 탭해 목재와 석재를 모읍니다.
- 하단 바에서 건물을 고르고 빈 땅을 탭한 뒤 **짓기**를 누릅니다. 건물은 2×2칸을 차지합니다.
- 건물을 탭하면 업그레이드(최대 3레벨)와 철거를 할 수 있고, 시장에서는 자원을 금화로 팔 수 있습니다.

## 게임 시스템

| 건물 | 비용 | 일손 | 효과 | 조건 |
|---|---|---|---|---|
| 마을회관 | – | – | 주민 +5/레벨 | 시작 건물 |
| 오두막 | 목재 20 | – | 주민 +3/레벨 | |
| 밀밭 | 목재 15 | 2 | 식량 +1.2/초 (겨울 정지) | |
| 벌목소 | 목재 25, 석재 10 | 2 | 목재 +0.8/초 | |
| 채석장 | 목재 30 | 2 | 석재 +0.6/초 | |
| 시장 | 목재 40, 석재 20 | 2 | 금화 +0.8/초, 자원 판매 | |
| 빵집 | 목재 35, 석재 30, 금화 20 | 2 | 식량 +1.6/초 | 회관 Lv2 |
| 선술집 | 목재 60, 석재 40, 금화 50 | 3 | 금화 +1.6/초, 주민 증가 가속 | 회관 Lv2 |

- **주민과 식량**: 주민 1명당 식량 0.12/초를 소비합니다. 식량이 바닥나면 주민이 떠납니다.
- **계절**: 하루 30초, 5일마다 봄 → 여름 → 가을 → 겨울로 바뀝니다.
- **스킬**: 농사·건축·교역 경험치가 쌓이면 레벨이 오르고 생산량과 판매가가 늘어납니다.
- **퀘스트**: 15단계 진행 퀘스트와 보상.
